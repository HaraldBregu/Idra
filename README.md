# Idra documentation

Use these guides to deploy, operate, secure, and contribute to Idra:

- [A2A client integration](docs/CLIENT.md) explains how clients discover, authenticate with, and invoke the agent.
- [Using Idra over A2A](docs/USAGE.md) covers deployment, provider configuration, client registration, OAuth token acquisition, A2A operations, and troubleshooting.
- [Contributing to Idra](CONTRIBUTING.md) covers local development, repository conventions, verification, and pull requests.
- [Security policy](docs/SECURITY.md) defines supported versions, vulnerability scope, and private reporting instructions.
- [Changelog](CHANGELOG.md) records release changes.
