## Large Language Models

Official references: [AI21 Jamba models](https://docs.ai21.com/docs/jamba-foundation-models), [AI21 chat request](https://docs.ai21.com/reference/jamba-1-6-api-ref).

Official model families: Jamba Large, Jamba Mini, Jamba2 Mini, Jamba2 3B, and versioned Jamba API endpoints.

Friday status: Friday has an explicit default agent catalog for AI21.

| `jamba-mini` | Jamba Mini |
| `jamba-1.5-large` | Jamba 1.5 Large |
| `jamba-1.5-mini` | Jamba 1.5 Mini |

## Agent Systems

Official references: [AI21 overview](https://docs.ai21.com/docs/overview), [AI21 Maestro](https://docs.ai21.com/docs/maestro-overview).

Official model families: AI21 Maestro and managed knowledge-agent systems built around model selection, RAG, web search, and validation.

Friday status: Friday does not model AI21 Maestro as a separate provider catalog.

## Runtime Notes

- Uses the generic OpenAI Chat Completions-compatible adapter.
- Confirm endpoint compatibility before using AI21 as the main agent provider.
- Friday does not save or pass reasoning effort for AI21.
