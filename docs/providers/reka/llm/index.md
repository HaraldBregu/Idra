# Reka AI Large Language Models

This folder documents Reka AI large language models.

Capability values are based on current Reka documentation. `Not documented`
means no official provider docs found for that capability.

| Model | Status | Skills | Tools | Reasoning | Notes |
| --- | --- | --- | --- | --- | --- |
| `reka-flash` | Documented | Not documented | Yes | Not documented | Reka documents function calling for chat models; reasoning steps are documented for the separate `reka-flash-research` model. |
| `reka-edge-2603` | Documented | Not documented | Yes | Not documented | Reka documents Edge 2603 as a compact open model with tool-use support; no model reasoning-control docs were found. |
