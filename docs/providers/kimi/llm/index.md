# Kimi Large Language Models

This folder documents Kimi large language models.

Capability values are based on current Moonshot AI and Kimi documentation.
`Not documented` means no official provider docs found for that capability.

| Model | Status | Skills | Tools | Reasoning | Notes |
| --- | --- | --- | --- | --- | --- |
| `kimi-k2.6` | Documented | Not documented | Yes | Yes | Kimi documents K2.6 with tool use and thinking-mode support. |
| `kimi-k2.5` | Documented | Not documented | Yes | Yes | Kimi documents K2.5 modes for instant, thinking, agent, and agent-swarm workflows. |
| `kimi-k2-thinking` | Documented | Not documented | Yes | Yes | Kimi documents this as the reasoning-focused K2 variant with tool-use support. |
