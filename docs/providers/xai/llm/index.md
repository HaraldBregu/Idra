# xAI Large Language Models

This folder documents xAI large language models.

Capability values are based on current xAI documentation. `Runtime` means the
feature is documented for Grok Build or the API runtime, not as a standalone
model flag.

| Model | Status | Skills | Tools | Reasoning | Notes |
| --- | --- | --- | --- | --- | --- |
| `grok-4.3` | Documented | Runtime | Yes | Yes | xAI documents Grok 4.3 with function calling, built-in tools, and configurable reasoning; Grok Build documents skills in the runtime. |
| `grok-build-0.1` | Documented | Runtime | Runtime | Not found | xAI documents Grok Build skills and plugins, but no direct official model capability page was found for this model string. |
