# Z.ai Large Language Models

This folder documents Z.ai large language models.

Capability values are based on current Z.ai documentation. `Not found` means no
official provider documentation was found for that exact model string.

| Model | Status | Skills | Tools | Reasoning | Notes |
| --- | --- | --- | --- | --- | --- |
| `glm-5.1` | Documented | Not documented | Yes | Yes | Z.ai documents GLM-5.1 as a reasoning-capable model with tool/function calling support. |
| `glm-5` | Documented | Not documented | Yes | Yes | Z.ai overview documentation lists GLM-5-class chat models with reasoning and tool/function support. |
| `glm-5-turbo` | Documented | Not found | Not found | Not found | No direct official model capability page was found for this exact model string. |
