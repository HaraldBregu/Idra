This folder documents Deepgram speech-to-text models.

| Model | API Type | Status | Notes |
| --- | --- | --- | --- |
| `nova-3` | Batch and stream APIs | Documented | General-purpose speech-to-text model for recorded or live audio. |
| `flux` | Stream API | Documented | Friday catalog id mapped to Deepgram Flux realtime models for conversational dictation. |
