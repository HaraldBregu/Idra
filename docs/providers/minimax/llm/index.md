# MiniMax Large Language Models

This folder documents MiniMax large language models.

Capability values are based on current MiniMax documentation. `Not documented`
means no official provider docs found for that capability.

| Model | Status | Skills | Tools | Reasoning | Notes |
| --- | --- | --- | --- | --- | --- |
| `MiniMax-M2.7` | Documented | Not documented | Yes | Yes | MiniMax documents M2.7 as an agentic model with tool-use APIs and reasoning behavior. |
| `MiniMax-M2.5` | Documented | Not documented | Yes | Yes | MiniMax documents M2.5 for search/tool use and reasoning-focused agent workflows. |
