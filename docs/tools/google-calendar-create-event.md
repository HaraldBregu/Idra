# Google Calendar create_event

Google Calendar `create_event` adds a new event.

## How It Is Used

- Used when the user asks Friday to put something on the calendar.
- Creates a scheduled event with the requested title, time, and relevant details.
- Fits meeting, appointment, reminder, and planning workflows.

## Boundaries

- It changes the user's calendar.
- Friday should clarify missing essentials such as date or time before creating
  the event.
