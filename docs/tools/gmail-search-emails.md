# Gmail search_emails

Gmail `search_emails` finds messages that match the user's request.

## How It Is Used

- Used to locate emails by sender, subject, date, label, or topic.
- Helps Friday narrow a mailbox question before opening individual messages.
- Supports workflows such as finding invoices, recent threads, or messages from
  a person.

## Boundaries

- Search results are a starting point, not the full message context.
- Friday should read a specific email before summarizing details from it.
