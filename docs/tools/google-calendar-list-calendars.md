# Google Calendar list_calendars

Google Calendar `list_calendars` shows the calendars available to the account.

## How It Is Used

- Used when the user has multiple calendars and the right one is unclear.
- Helps Friday choose between personal, work, shared, or project calendars.
- Can prepare for event search, creation, or updates.

## Boundaries

- It lists calendars, not event details.
- Friday should not assume a calendar choice when the request is ambiguous.
