# Gmail create_draft

Gmail `create_draft` prepares an email draft without sending it.

## How It Is Used

- Used when the user wants help writing an email but wants a chance to review it.
- Saves the message as a draft in Gmail.
- Fits workflows where sending should remain a deliberate user decision.

## Boundaries

- It does not send the message.
- Draft content should match the user's stated recipient, subject, and intent.
