# Microsoft Teams Catalog Tools

Microsoft Teams lists tool names for future connector work: `search`, `fetch`,
`get_chat_members`, and `get_profile`.

## How They Are Used

- These names document the intended Teams connector surface.
- The intended use is message search, message fetch, member review, and account
  profile lookup.
- They support Settings, scopes, and future implementation planning.

## Current Status

Default local agent execution is not implemented for Microsoft Teams yet.
