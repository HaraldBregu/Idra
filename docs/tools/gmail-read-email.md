# Gmail read_email

Gmail `read_email` opens one email message.

## How It Is Used

- Used after a search result or user-provided message reference identifies a
  specific email.
- Lets Friday summarize, extract action items, or answer questions about that
  message.
- Provides the message context needed before replying, drafting, or trashing.

## Boundaries

- It reads one selected message at a time.
- Email content should be treated as private user data.
