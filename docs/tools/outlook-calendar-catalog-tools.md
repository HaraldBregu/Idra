# Outlook Calendar Catalog Tools

Outlook Calendar lists tool names for future connector work: `search_events`,
`fetch_event`, `fetch_events_batch`, `list_events`, and `get_profile`.

## How They Are Used

- These names document the intended Outlook calendar connector surface.
- The intended use is event search, event reading, event listing, and account
  profile lookup.
- They support Settings, scopes, and future implementation planning.

## Current Status

Default local agent execution is not implemented for Outlook Calendar yet.
