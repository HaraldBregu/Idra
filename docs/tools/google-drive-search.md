# Google Drive search

Google Drive `search` uses the connector's general Drive search path.

## How It Is Used

- Used to find Drive items when a broad search is appropriate.
- Can locate documents, folders, or files based on the user's request.
- Helps Friday choose a specific item for follow-up reads or actions.

## Boundaries

- Search results are not the same as file content.
- Friday should narrow the search when the user provides constraints.
