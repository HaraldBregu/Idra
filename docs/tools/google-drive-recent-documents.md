# Google Drive recent_documents

Google Drive `recent_documents` finds recent document-style files.

## How It Is Used

- Used when the user asks for recently worked-on documents.
- Helps Friday surface docs that are likely to be relevant to current work.
- Can be a first step before reading or summarizing a selected document.

## Boundaries

- It is document-focused, not a full Drive inventory.
- Friday should open only documents needed for the request.
