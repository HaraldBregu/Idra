# Gmail get_recent_emails

Gmail `get_recent_emails` shows recently received or updated messages.

## How It Is Used

- Used when the user asks what is new or recent in Gmail.
- Helps Friday quickly surface the latest mailbox activity.
- Can provide a short list before the user chooses what to open.

## Boundaries

- Recent does not always mean relevant.
- Friday should avoid reading more messages than the task requires.
