# Google Drive get_file_permissions

Google Drive `get_file_permissions` reviews who can access a Drive file.

## How It Is Used

- Used when the user asks who a file is shared with.
- Helps Friday explain access and sharing state.
- Can support decisions before changing or sending a document.

## Boundaries

- It reviews permissions; it does not change them.
- Sharing information can be sensitive and should be kept relevant.
