# SharePoint Catalog Tools

SharePoint lists tool names for future connector work: `get_site`, `search`,
`list_recent_documents`, `fetch`, and `get_profile`.

## How They Are Used

- These names document the intended SharePoint and OneDrive connector surface.
- The intended use is site lookup, document search, recent document review,
  document fetch, and account profile lookup.
- They support Settings, scopes, and future implementation planning.

## Current Status

Default local agent execution is not implemented for SharePoint yet.
