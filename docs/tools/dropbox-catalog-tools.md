# Dropbox Catalog Tools

Dropbox lists tool names for future connector work: `search`, `fetch`,
`search_files`, `fetch_file`, `list_recent_files`, and `get_profile`.

## How They Are Used

- These names document the intended Dropbox connector surface.
- They support Settings, scopes, and future implementation planning.
- The intended use is file search, file fetch, recent file review, and account
  profile lookup.

## Current Status

Default local agent execution is not implemented for Dropbox yet.
