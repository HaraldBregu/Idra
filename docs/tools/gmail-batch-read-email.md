# Gmail batch_read_email

Gmail `batch_read_email` opens a small group of email messages together.

## How It Is Used

- Used when the user asks about several known emails.
- Helpful for comparing related messages or summarizing a short thread set.
- Reduces repeated mailbox reads when the selected messages are already known.

## Boundaries

- It should stay small and relevant.
- It should not be used to bulk-read a mailbox without a clear need.
