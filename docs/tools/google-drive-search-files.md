# Google Drive search_files

Google Drive `search_files` finds Drive files.

## How It Is Used

- Used when the user describes a file by name, topic, type, or location.
- Helps Friday narrow Drive before reading content or checking permissions.
- Supports workflows such as finding documents, spreadsheets, or recent assets.

## Boundaries

- Search results may need follow-up reads for content.
- Friday should avoid broad searches when the user gave a clear scope.
