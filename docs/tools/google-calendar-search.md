# Google Calendar search

Google Calendar `search` searches calendar content broadly.

## How It Is Used

- Used when the user asks for calendar items by topic, time range, or phrase.
- Helps Friday find relevant calendar entries before opening one.
- Works as a broad discovery tool for calendar questions.

## Boundaries

- Search results may need a follow-up read for exact details.
- It should be scoped to the relevant calendar or time range when possible.
