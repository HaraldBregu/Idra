# Google Drive get_file_metadata

Google Drive `get_file_metadata` shows details about a Drive file.

## How It Is Used

- Used when Friday needs facts such as file name, owner, type, or timestamps.
- Helps identify the right file before reading, sharing, or changing it.
- Can answer organizational questions without opening file content.

## Boundaries

- It does not read the document body.
- It should not be treated as proof of file content.
