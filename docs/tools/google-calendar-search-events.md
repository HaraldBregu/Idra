# Google Calendar search_events

Google Calendar `search_events` finds events that match a request.

## How It Is Used

- Used for event-focused questions such as meetings next week or appointments
  with a person.
- Helps Friday narrow the calendar before reading or changing an event.
- Supports schedule review and planning workflows.

## Boundaries

- Search results should be verified before updates or deletion.
- Friday should keep searches bounded by time when the user gives a timeframe.
