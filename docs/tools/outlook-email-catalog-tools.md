# Outlook Email Catalog Tools

Outlook Email lists tool names for future connector work: `get_profile`,
`list_messages`, `search_messages`, `get_recent_emails`, `fetch_message`, and
`fetch_messages_batch`.

## How They Are Used

- These names document the intended Outlook mail connector surface.
- The intended use is mailbox search, recent email review, message reading, and
  account profile lookup.
- They support Settings, scopes, and future implementation planning.

## Current Status

Default local agent execution is not implemented for Outlook Email yet.
