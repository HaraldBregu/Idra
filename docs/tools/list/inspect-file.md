# inspect_file

`inspect_file` checks what a file is before the agent decides what to do with it.

## Use For

- Checking file type, size, or metadata.
- Previewing a file safely.
- Understanding binary or image files.

## Do Not Use For

- Editing files.
- Reading full text when exact text matters.

## Keep In Mind

Inspection helps choose the right next step. It does not replace reading important text.
