# tool_search

`tool_search` searches a hidden tool catalog.

## How It Is Used

- Used when there are too many possible tools to show all at once.
- Helps Friday find a relevant hidden tool by purpose or name.
- Keeps the prompt smaller while preserving access to a larger tool catalog.

## Boundaries

- It is only useful when tool-search compaction is enabled.
- Finding a tool does not mean it should be used without checking relevance and
  safety.
