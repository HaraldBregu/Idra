# Gmail search_email_ids

Gmail `search_email_ids` finds matching message identifiers.

## How It Is Used

- Used when Friday needs a compact list of messages for follow-up actions.
- Helpful before reading a small batch of selected emails.
- Keeps broad mailbox searches from returning more content than needed.

## Boundaries

- It does not provide the full email body.
- Follow-up reads should stay limited to messages relevant to the request.
