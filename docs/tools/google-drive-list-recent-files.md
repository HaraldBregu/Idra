# Google Drive list_recent_files

Google Drive `list_recent_files` shows recently used files.

## How It Is Used

- Used when the user asks for recent Drive activity or recent files.
- Helps Friday surface likely candidates without a precise file name.
- Can be a first step before reading or sharing a specific file.

## Boundaries

- Recent files may not be relevant to the user's goal.
- Friday should not open file contents unless needed.
