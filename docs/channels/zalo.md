# Zalo Channel

Catalog metadata for Friday's Zalo channel.

| Field | Value |
| --- | --- |
| Channel id | `zalo` |
| Label | Zalo |
| Aliases | `zl` |
| Runtime | Catalog-only |

Zalo can be configured in Settings, but Friday does not currently bundle a Zalo
runtime adapter.
