# Matrix Channel

Catalog metadata for Friday's Matrix channel.

| Field | Value |
| --- | --- |
| Channel id | `matrix` |
| Label | Matrix |
| Aliases | none |
| Runtime | Catalog-only |

Matrix can be configured in Settings, but Friday does not currently bundle a
Matrix runtime adapter.
