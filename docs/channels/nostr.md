# Nostr Channel

Catalog metadata for Friday's Nostr channel.

| Field | Value |
| --- | --- |
| Channel id | `nostr` |
| Label | Nostr |
| Aliases | none |
| Runtime | Catalog-only |

Nostr can be configured in Settings, but Friday does not currently bundle a
Nostr runtime adapter.
