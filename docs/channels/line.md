# LINE Channel

Catalog metadata for Friday's LINE channel.

| Field | Value |
| --- | --- |
| Channel id | `line` |
| Label | LINE |
| Aliases | none |
| Runtime | Catalog-only |

LINE can be configured in Settings, but Friday does not currently bundle a LINE
runtime adapter.
