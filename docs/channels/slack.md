# Slack Channel

Catalog metadata for Friday's Slack channel.

| Field | Value |
| --- | --- |
| Channel id | `slack` |
| Label | Slack |
| Aliases | none |
| Runtime | Catalog-only |

Slack can be configured in Settings, but Friday does not currently bundle a
Slack runtime adapter.
