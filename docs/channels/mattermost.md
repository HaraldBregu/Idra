# Mattermost Channel

Catalog metadata for Friday's Mattermost channel.

| Field | Value |
| --- | --- |
| Channel id | `mattermost` |
| Label | Mattermost |
| Aliases | none |
| Runtime | Catalog-only |

Mattermost can be configured in Settings, but Friday does not currently bundle a
Mattermost runtime adapter.
