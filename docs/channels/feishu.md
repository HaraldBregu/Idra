# Feishu Channel

Catalog metadata for Friday's Feishu channel.

| Field | Value |
| --- | --- |
| Channel id | `feishu` |
| Label | Feishu |
| Aliases | `lark` |
| Runtime | Catalog-only |

Feishu can be configured in Settings, but Friday does not currently bundle a
Feishu runtime adapter.
