# QQ Bot Channel

Catalog metadata for Friday's QQ Bot channel.

| Field | Value |
| --- | --- |
| Channel id | `qqbot` |
| Label | QQ Bot |
| Aliases | none |
| Runtime | Catalog-only |

QQ Bot can be configured in Settings, but Friday does not currently bundle a QQ
Bot runtime adapter.
