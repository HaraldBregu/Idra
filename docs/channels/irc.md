# IRC Channel

Catalog metadata for Friday's IRC channel.

| Field | Value |
| --- | --- |
| Channel id | `irc` |
| Label | IRC |
| Aliases | `internet-relay-chat` |
| Runtime | Catalog-only |

IRC can be configured in Settings, but Friday does not currently bundle an IRC
runtime adapter.
