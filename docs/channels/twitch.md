# Twitch Channel

Catalog metadata for Friday's Twitch channel.

| Field | Value |
| --- | --- |
| Channel id | `twitch` |
| Label | Twitch |
| Aliases | `twitch-chat` |
| Runtime | Catalog-only |

Twitch can be configured in Settings, but Friday does not currently bundle a
Twitch runtime adapter.
