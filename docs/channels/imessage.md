# iMessage Channel

Catalog metadata for Friday's iMessage channel.

| Field | Value |
| --- | --- |
| Channel id | `imessage` |
| Label | iMessage |
| Aliases | `imsg` |
| Runtime | Catalog-only |

iMessage can be configured in Settings, but Friday does not currently bundle an
iMessage runtime adapter.
