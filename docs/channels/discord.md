# Discord Channel

Catalog metadata for Friday's Discord channel.

| Field | Value |
| --- | --- |
| Channel id | `discord` |
| Label | Discord |
| Aliases | none |
| Runtime | Catalog-only |

Discord can be configured in Settings, but Friday does not currently bundle a
Discord runtime adapter.
