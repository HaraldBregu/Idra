# WhatsApp Channel

Catalog metadata for Friday's WhatsApp channel.

| Field | Value |
| --- | --- |
| Channel id | `whatsapp` |
| Label | WhatsApp |
| Aliases | none |
| Runtime | Catalog-only |

WhatsApp can be configured in Settings, but Friday does not currently bundle a
WhatsApp runtime adapter.
