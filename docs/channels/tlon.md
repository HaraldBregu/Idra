# Tlon Channel

Catalog metadata for Friday's Tlon channel.

| Field | Value |
| --- | --- |
| Channel id | `tlon` |
| Label | Tlon |
| Aliases | none |
| Runtime | Catalog-only |

Tlon can be configured in Settings, but Friday does not currently bundle a Tlon
runtime adapter.
