# Modules

| Module | Description |
| --- | --- |
| agent | Runs the agent workflow, including startup context, system prompts, compaction, and execution setup. |
| browser | Provides browser runtime services, policy checks, types, and tool access for browser-based work. |
| channels | Manages message ingress, channel plugins, channel registry/catalog data, and channel-specific turns. |
| connectors | Defines and manages external service connector configuration, integration setup, and connector services. |
| cron | Schedules, validates, stores, and runs recurring tasks, including agent-driven scheduled work. |
