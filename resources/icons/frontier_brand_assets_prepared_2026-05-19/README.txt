Frontier AI provider brand assets package
Generated: 2026-05-19

Contents
- One folder per provider from the frontier provider list.
- official_downloaded_assets/ contains official raster assets that were directly downloadable.
- fallback_lobehub/ contains provider/model icon variants from @lobehub/icons-static-png and @lobehub/icons-static-svg.
- fallback_simpleicons/ contains SVG/PNG icon variants from simple-icons when available.
- download_links.txt preserves official/fallback asset URLs and direct ZIP links that were not downloadable here.
- source_info.json contains per-provider metadata.

Limitations
- Official ZIP brand kits could not be downloaded with the secure downloader because ZIP MIME types were blocked. The ZIP URLs are preserved in each provider folder.
- Official SVG URLs from some providers were not downloaded directly when the secure downloader rejected SVG MIME types; equivalent PNG/fallback SVG assets are included where available.
- No font files are included. The package was scanned for font extensions before zipping.
- This is not legal clearance. Check each provider's brand/trademark terms before public or commercial use.
